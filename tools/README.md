# Profile tools

Everything shown on [github.com/ammar197khan](https://github.com/ammar197khan) comes from this repository:

| File | What it is | How it changes |
| :--- | :--- | :--- |
| `README.md` (repo root) | The profile page: text, links, project table | Edit by hand |
| `assets/banner.svg`, `about.svg`, `toolkit.svg`, `nav-*.svg` | Artwork | Generated by `build-assets.mjs` |
| `assets/stats/*.svg` | Stats cards | Generated daily by GitHub Actions (`stats.mjs`) |
| `assets/portfolio-preview.jpg` | Featured project screenshot | Replace by hand |

## Updating text, links and projects

Edit `README.md` in the repo root, on GitHub (pencil icon) or locally, and commit. Changes show on the profile right away.

**Add a featured repository:** copy the `<table>` block under "Featured projects" and change the image, title, description, tech line and links. Save a screenshot (16:10, e.g. 1280×800 JPG) in `assets/`.

**Add an email link:** add a line under "Connect with me", for example `<a href="mailto:you@example.com">Email</a>`, or generate a matching button by adding `["email", "Email", "spark", false]` to `NAV` in `build-assets.mjs` and pointing it at `mailto:`.

## Updating skills, the banner or "What I build"

The content is at the top of `build-assets.mjs`:

- `HERO`: banner name, title line, subtitle and status pill
- `CONSOLE`: the animated agent console lines
- `FOCUS`: the six "What I build" tiles (icon, title, description)
- `TOOLKIT`: skill rows. Each item is `["Label", "siIconName"]` for a brand logo from [Simple Icons](https://simpleicons.org) (search the site, then use `si` + the slug, e.g. `siFastapi`), or `["Label", null, "glyph"]` for a neutral icon (glyph names are in `GLYPHS` in `lib.mjs`).
- `NAV`: the pill buttons

Then regenerate and commit:

```bash
cd tools
npm install        # first time only
npm run assets
cd ..
git add assets
git commit -m "Update profile artwork"
git push
```

Also update the "Toolkit as text" table and the image `alt` text in `README.md` so they match.

## Stats cards

`.github/workflows/stats.yml` runs `stats.mjs` every day at 03:17 UTC, and whenever the stats code changes. It reads public activity from the GitHub API with the built-in `GITHUB_TOKEN` and commits the cards only if something changed. Every number comes from GitHub; nothing is estimated.

- **Refresh now:** repository → **Actions** → **Update profile stats** → **Run workflow**.
- **Count private work:** turn on **Settings → Public profile → Contributions & activity → Include private contributions on my profile**. Your contribution totals and calendar will then include private contributions (counts only, no details).
- **Paused schedule:** GitHub pauses scheduled workflows in repositories with no activity for 60 days. If the cards stop updating, open the Actions tab and re-enable the workflow.
- **Run locally:** `GITHUB_TOKEN=<token> npm run stats` (PowerShell: `$env:GITHUB_TOKEN = gh auth token; npm run stats`).

## Fonts and icons

Text in the artwork is converted to vector outlines, so it looks the same in every browser. Fonts: Space Grotesk, Inter and JetBrains Mono (SIL Open Font License, licences in `fonts/`). Brand icons: [Simple Icons](https://simpleicons.org) (CC0). Brand names and logos belong to their owners.
